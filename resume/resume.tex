		\\ {\footnotesize\textcolor{bluegray}{\faGithubAlt~\href{https://github.com/pooriaaskarim/logd}{pooriaaskarim/logd} $\cdot$ \faCube~\href{https://pub.dev/packages/logd}{pub.dev/packages/logd}}}}
		\item[] {\small\textit{A structured logging library for Dart/Flutter. Loggers are organized in a configurable hierarchy, log records are treated as formatted data rather than raw strings, and output is offloaded to a background thread---so logging never competes with the application.}}
		\item Organized loggers in a \textbf{dot-separated hierarchy} with lazy config inheritance---changes to a parent propagate automatically to all descendants, without manual cache invalidation.
		\item Separated \textbf{formatting from rendering}: log records are structured into a semantic document first, then laid out for the target output surface (terminal, file, JSON)---switching targets requires no changes at the call site.
		\item Offloaded all output to a \textbf{background isolate via Dart FFI}, with built-in backpressure---ensuring the logging pipeline never blocks the application's main thread under load.
		\item Shipped as an \textbf{ecosystem of satellite packages}: \texttt{logd\_sqlite} (SQLite storage), \texttt{logd\_network} (HTTP batching \& live dashboard), and \texttt{logd\_linters} (static analysis)---each independently adoptable.
        \\ \chip{Hierarchical Config} \chip{Structured Logging} \chip{Background Isolate / FFI} \chip{Zero-GC Rendering} \chip{Terminal Layout Engine}
